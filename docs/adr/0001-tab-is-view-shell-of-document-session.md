# 标签页是文档会话的视图外壳

编辑窗口从"一个窗口一个文档"改为"一个窗口多个标签页"。我们决定：标签页只是文档会话的视图外壳，一个标签页恒等于一个文档会话；会话类型（kind）属于文档会话，不属于标签页；窗口持有多个会话，同一时刻只有一个活动会话。

## Considered Options

- **标签页持有 0 或 1 个会话**（图片标签页可以没有会话）：否决。这会让"有没有会话"变成标签页的一个状态维度，关闭、修改检查、重启恢复、外部变更全都要写两套分支。
- **引入 document 作为 kind 载体，session 降级为 markdown 的编辑态**：否决。这是纯改名成本，两个包内所有 `document.*` 命令、文档运行时、store 字段都要跟着动，换不来新能力。

## Consequences

- 将来增加图片 / 文本类型时，是给文档会话增加 kind，不是给标签页增加类型。
- 窗口级状态（视图模式、侧边栏显隐）不属于任何标签页，切标签不改变它们。
- 未保存确认、重启恢复、外部变更都以文档会话为单位，不引入第二类实体。

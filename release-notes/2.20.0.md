# 2.20.0

## 新增

- 编辑页与预览页之间切换时新增阅读位置交接：在编辑区滚动到某处后切到预览页，预览页会自动定位到对应内容；从预览页切回编辑页同样按对应位置恢复。位置精确到行内，反复来回切换也不会逐渐偏移。
- 文件管理栏新增「默认目录」配置，可在“设置 > 文件管理栏”中指定一个目录；当文件管理栏没有可跟随的当前文档目录时（例如新建草稿），会自动展示该目录作为兜底，且不会打断当前正在浏览的目录。默认目录不存在或被删除时会自动回到空态。

## 优化

- 文件管理栏宽度调整后会被记住：拖动分隔条改变宽度后自动保存，重启应用或切换视图后保持上次的宽度。
- Linux 版 AppImage 的桌面集成说明更新，推荐使用 Gear Lever（支持一键集成到应用菜单、拖放添加与更新管理），也可继续使用 AppImageLauncher 等工具。

## 修复

- 修复应用已在运行时，双击 Markdown 文件有时无法打开的问题；当打开请求携带的信息不完整时，现在会回退使用启动参数中的文件路径，路径包含空格等特殊字符也能正常在已有窗口中打开。

# 2.19.8

## 新增

- 预览区新增 `\(...\)` 行内公式与 `\[...\]` 块级公式写法，可与原有的 `$...$`、`$$...$$` 一起使用；中英文引导页同步新增「数学公式」章节，给出行内公式、块级公式以及列表内公式的完整写法示例。
- 关闭存在未保存修改的文档时，确认弹窗提供「保存并退出」选项，可一次性完成保存与关闭，不必先手动保存再关窗口；保存与关闭由同一流程处理，保存过程中取消操作也不会留下迟到的关窗行为。弹窗的两个选项同时改为「保存并退出 / 直接退出」，并加宽弹窗，中英文下按钮都不再折行。
- Linux 平台新增 `AppImage` 免安装单文件格式，随 GitHub Release 一起发布，下载后即可运行；README 中补充了对应的运行说明，包含可执行权限、桌面集成和 FUSE 依赖三部分。

## 修复

- 修复预览区中相邻两张图片紧贴显示、没有间距的问题，各预览主题下都会按主题自身的段落间距留出间隔。

# 2.22.2

## 优化

- 优化了深色主题下的启动与开窗观感：启动遮罩与窗口背景色会和当前主题保持一致，深色主题下启动应用、打开设置 / 关于 / 引导 / 导出窗口时不再出现白色闪烁
- 优化了启动遮罩的消失时机：改为等首屏内容真正可看后再移除，内容就绪后立即显示，不再按固定时长淡出，也不会过早消失露出空白
- 优化了启动性能：目录高亮计算与水印绘制推迟到首屏就绪后执行，截图、自动更新、图片上传等模块改为按需加载，减少启动耗时与资源占用
- 优化了 PDF 导出的深色主题支持：深色主题下导出的 PDF 会保持深色外观，页眉页脚文字颜色自动适配，不再被强制切换为浅色主题，文件菜单中「不支持暗黑主题」的提示也已取消

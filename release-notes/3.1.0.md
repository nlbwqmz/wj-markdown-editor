# 3.1.0

## 新增

- 自动保存新增「关闭标签时」这一时机：在设置中开启后，关闭有未保存修改的标签会先保存再关闭；关闭后台标签时界面不会跳到该标签上，保存与关闭都在后台完成。默认不开启，保持原有确认弹窗的行为不变。
- 标签栏新增两种磁盘状态提示：文件被删除或移动时，文件名显示为黄色并带删除线，鼠标悬停可看到原因，同时「在资源管理器中显示」置灰（复制文件名、复制路径仍可用，方便按路径找回文件）；磁盘上的文件存在尚未处理的外部改动时，文件名同样给出黄色提示与悬停说明，便于区分「文件已不在盘上」与「有新版本待处理」。

## 优化

- 关闭窗口时的自动保存放宽了限制：开启「窗口关闭时」自动保存后，无论有几个未保存标签、是否当前标签，都会逐个保存后再关窗，不再出现连续弹窗；若存在未命名草稿或尚未处理的外部改动，仍会回到确认弹窗，由你决定如何保存。
- 批量关闭与自动保存联动：「关闭其他」「关闭左侧」「关闭右侧」在开启「关闭标签时」自动保存后，会把有未保存修改的标签一并保存后关闭，并把因未命名草稿、外部变更待处理、正在保存或保存失败而没有关闭的标签汇总成一条提示，不再逐个弹窗；这几项菜单的可用状态也与实际关闭结果一致，不再出现菜单可点却没有反应、或能关闭却显示为灰色。
- 从文件管理栏在当前窗口打开 Markdown 文件时，直接新开一个标签，不再先询问「先保存再切换 / 不保存并切换」——在当前窗口打开不会替换或丢失正在编辑的文档，这一步选择已经没有必要。

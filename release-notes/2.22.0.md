# 2.22.0

## 新增

- 新增语言「自动（跟随系统）」选项并作为默认设置：中文系统显示中文，其他语言环境显示英文；界面文案与系统提示（打开失败、保存失败、窗口加载失败等）都按同一规则切换，启动时首屏即为正确语言，不再先显示默认语言再切换；也可在顶部语言菜单或设置页中手动固定为中文或英文

## 优化

- 优化了 Linux AppImage 的运行条件：安装包内置静态运行环境，不再要求系统预先安装 FUSE2，此前部分发行版（如 Ubuntu 24.04+）需要手动安装 libfuse2t64 / libfuse2 才能启动，现在下载后赋予执行权限即可直接运行；对应下载文件名简化为 `wj-markdown-editor-x86_64-<版本>.AppImage`
- 优化了 Linux 安装包的应用信息：安装包内附带标准的应用元数据（名称、简介、截图、版本与更新日期），在支持应用商店或软件中心的发行版上可被正确识别与展示，便于通过发行版渠道安装与更新

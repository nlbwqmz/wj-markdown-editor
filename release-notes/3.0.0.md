# 3.0.0

## 新增

- 单窗口多标签页文档会话：可在同一个窗口里同时打开多个 Markdown 文档，每个标签独立保留撤销历史、光标位置与视图模式，切换标签互不干扰。
- 完整的标签管理能力：支持拖拽重排标签（顺序会持久化，下次启动按新顺序恢复）、批量关闭、关闭其它、关闭左侧、关闭右侧、移动到新窗口、复制文件名、复制路径，以及在资源管理器中显示。
- 标签栏横向滚动：标签较多时可用鼠标滚轮横向滚动，切换标签时活动标签会自动滚入可视区。
- 标签组恢复：关闭窗口时保存标签组，下次启动恢复标签顺序与上次活动标签；已不存在的文件会自动跳过，并在启动完成后弹窗列出被跳过的文件。
- 新增「恢复标签」启动策略，可在不恢复、直接启动时恢复、总是恢复之间选择。
- 新增「新建窗口」能力，便于并排查看多个文档，并提供对应的快捷键配置项。
- 自动保存新增「切换标签时」这一时机，与窗口失焦、关闭窗口两种时机并存。
- 设置页新增设置项搜索：支持中英文名称、关键词与快捷键匹配，跨标签展示命中项，按 `Esc` 清空。
- 设置页按 6 个标签页组织（常规 / 外观 / 编辑器 / 快捷键 / 文件与图片 / 导出与水印），快捷键设置按「全局快捷键」与「编辑器快捷键」分组展示。
- 斜杠命令补全扩充：新增日期时间、任务列表、Mermaid 图表、文字颜色等命令，支持中英文与拼音别名，并按命令类型分组展示。
- 文件管理栏新增显示范围配置：可在全部文件与仅支持的文件之间切换，目录始终显示。

## 优化

- 顶部栏视图模式切换改为按钮组，并在提示中显示对应快捷键；顶部栏同时新增侧边栏开关。
- 文件管理栏的新建与重命名弹窗改用统一的名称输入组件，名称校验提示更明确（覆盖系统保留名、特殊字符、结尾点等情况），新建 Markdown 时自动补全 `.md` 后缀。
- 滚动条改为自绘样式，长列表与标签栏在明暗主题下的外观与滚动手感更一致。
- 设置页样式与主题变量统一，修正选中态、悬停态的层级关系，使用更清晰。
- 关闭有未保存修改的标签时会单独确认处理方式；关闭窗口时若有多个未保存标签，会汇总提示。
- 双击 `.md` 文件或通过第二实例打开文件时，默认在最近活动的编辑窗口以新标签打开；文件已在其他窗口打开时会切换到对应窗口。
- 快捷键配置项扩充至 34 项。
- 更新应用图标，统一各平台窗口图标与系统任务栏 / 停靠栏显示。
- 系统字体列表增加兜底方案，避免字体下拉出现空列表。

## 修复

- 修复关闭包含多个标签的窗口时，后台标签的会话未被一并处理的问题。
- 修复关闭没有未保存修改的后台标签时会先切换到该标签再关闭的问题。
- 修复启动恢复标签组时，首个已不存在的文件被退化成空白新文档的问题。
- 修复多标签之间输入法组合输入状态相互影响、导致内容同步异常的问题。
- 修复通过文件关联或双击方式启动打开文件时路径解析出错的问题。
- 修复设置页悬浮层背景色异常的问题。

## 移除

- 移除了「启动时打开最近一次记录」的启动恢复方式（含对应设置项与入口），改由「恢复标签」策略接管；若需要启动后回到上次编辑状态，把「恢复标签」设为「直接启动时恢复」或「总是恢复」即可。

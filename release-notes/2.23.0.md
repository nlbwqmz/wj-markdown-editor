# 2.23.0

## 新增

- 新增「源码 / 双栏 / 预览」三种视图模式，替代原来的视图切换：顶部视图按钮改为下拉菜单，主菜单「视图」中也可选择，当前模式带勾选标记；设置页「启动视图」同步改为三选一（默认双栏模式），启动时统一进入编辑页并按所选视图展示
- 新增侧边栏：原文件管理栏与大纲面板合并为带「文件」「大纲」标签页的侧边栏，设置页可选择启动时默认关闭、显示文件或显示大纲（默认关闭），侧边栏宽度可拖拽调整（220–420px）并被记住
- 新增 YAML front matter 支持：文档开头的 `---` ... `---` 元数据块会按 YAML 代码块渲染并高亮，内容为空时不显示，未正常闭合时仍按普通 Markdown 处理
- 新增纯预览模式的空文档提示：文档为空时显示「文档内容为空」并提供「去编辑」按钮，一键切回双栏模式继续编辑

## 优化

- 优化了大纲：大纲改为直接解析 Markdown 源文本，不再依赖预览区渲染，源码模式下同样可用；无预览时随编辑区滚动高亮当前章节，点击大纲直接跳转到编辑器对应行
- 优化了纯预览模式的阅读体验：自动隐藏工具栏，预览区按设置的预览宽度居中显示；从纯预览切回其他视图时，阅读位置会交接给编辑器，不再跳回文档顶部
- 优化了菜单选项对齐：视图、语言等菜单的未选中项统一预留勾选图标占位，切换选中项时文字不再左右移动
- 优化了侧边栏的性能开销：大纲面板切走后立即卸载，不再在隐藏状态下测量标题位置与重建索引；仅当编辑页处于激活状态且大纲可见时才跟随滚动更新高亮

## 注意

- 升级后侧边栏默认为关闭状态，宽度默认 280px：旧版本中的「文件管理栏显示 / 宽度」「大纲显示 / 宽度」设置已被新的侧边栏设置取代
- 原「视图切换」快捷键已拆分为「源码模式 / 双栏模式 / 预览模式」三个快捷键，升级后旧快捷键不再生效，需要按需重新设置
- 独立预览页已移除，预览统一为编辑页中的「预览模式」

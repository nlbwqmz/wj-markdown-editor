# 3.1.1

## 优化

- 用户数据统一收拢：配置文件、最近文件、标签组与日志不再写入系统「文档」目录，而是集中保存在应用自己的用户数据目录下，便于与个人文档区分，备份或清理时也不容易误删或误留。
- 旧数据自动迁移：升级后首次启动会把旧版留在「文档/wj-markdown-editor」下的配置、最近文件、标签组与日志搬到新位置，界面偏好、最近文件列表和上次打开的标签组都保持不变；若新位置已有同名数据，则以新位置为准，不会被旧数据覆盖。
- 迁移过程不阻塞使用：迁移失败时应用照常启动、继续使用现有数据，并在下次启动自动重试；迁移完成后不再回读旧目录，之后即使删掉新位置的配置，旧文件也不会「复活」。
- 数据目录支持按环境变量指定，第三方发行版可以把配置与日志放到各自规范的位置；常规安装无需任何设置。

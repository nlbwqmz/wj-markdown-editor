# 3.0.1

## 新增

- 标签页操作快捷键：可在设置中为「下一个标签页」「上一个标签页」「关闭标签页」分别配置按键。默认不预置键位，需要时再自行开启，不会影响既有的操作习惯。

## 优化

- 标签页的鼠标点击与快捷键操作统一为同一套行为：切换标签前会先同步当前文档内容，开启「切换标签时」自动保存后不会再写入旧内容；连续按键会按顺序合并处理，不会出现重复切换或反复弹出提示。

## 修复

- 修复暗色模式下启动时首帧闪白的问题：启动阶段即按暗色主题绘制，标题栏与内容区不再先闪一下亮色。
- 修复快速切换或关闭标签后，文件管理栏与外部文件变更监听仍停留在上一个标签的问题，现在始终跟随当前标签。
- 修复关闭有未保存修改的文档时，按 `Esc` 关闭确认弹窗后弹窗又再次弹出的问题：`Esc` 现在等同于「取消」，会正常放弃本次关闭。
